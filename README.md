# Vyvid RDF Modelling Domain

Вивід: домен моделювання RDF

This domain holds the skill for how to model well in RDF and OWL, kept so that any project can use it. It holds no register.

- `skills/ontology-modelling` covers asking for declared terms before declaring one, modelling reality first, judgements evaluated from facts, deferred values, additive quantities, the open world, domain and range, simplifying a model without losing logical correctness, and designing for the runtime cost of a term.

A project adds its own terms, examples and layer rules to the skill with `.vyvid/skills/rdf-modelling/ontology-modelling.md`. How a triple store behaves, and how to write a query or a shape that runs in reasonable time, is in the Triple Stores domain.
